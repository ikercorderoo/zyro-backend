# Zyro

Proyecto final desarrollado por **Iker Cordero Luengo** y **Aitor Martinez Lora**.
Somos estudiantes del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) en el centro **Jaume Viladoms**.

## Sobre el Proyecto

Zyro es una plataforma web completa dividida en un frontend desarrollado con Next.js/React y un backend con Node.js/Express y base de datos PostgreSQL gestionada mediante Prisma. 
El sistema permite a profesionales ofrecer sus servicios, y a los clientes descubrir y reservar dichos servicios a través de un marketplace interactivo.

## Despliegue

- **Frontend:** Vercel
- **Backend & Base de datos:** Railway
